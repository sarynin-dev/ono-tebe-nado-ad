# Проект «Оно тебе надо»

Ссылка на репозиторий: https://github.com/sarynin-dev/ono-tebe-nado-ad

## Описание
Одностраничный сайт-лендинг интернет-аукциона вещей «Оно тебе надо». Проект выполнен по итогу первого и второго спринтов курса «Фронтенд-разработчик» Яндекс Практикума.

## Использованные технологии
- Семантическая разметка HTML5 (`header`, `main`, `section`, `article`, `nav`, `address`, `footer`).
- Современные методы раскладки CSS3: CSS Grid и Flexbox.
- Абсолютное позиционирование с использованием современных свойств (`inset: 0`) и управление контекстом наложения (`z-index`).
- Оформление типографики и переиспользуемые декоративные блоки (оверлей затемнения, контакты).
- Методология именования классов БЭМ (без привязки к номерам блоков).

## Локальный запуск
Для просмотра проекта откройте файл `index.html` в любом современном браузере.
